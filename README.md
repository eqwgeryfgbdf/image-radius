# 圖片圓角

**版本：** 1.0.0

調整文章圖片、封面、頭像、Logo 與網站圖示的圓角，可在設定頁與自訂器修改。

## 需求

- WordPress 6.0+
- PHP 8.0+（部分外掛標示 7.4+）

## 安裝

1. 下載本倉庫 zip，或 clone 後壓縮成資料夾
2. 上傳到 `wp-content/plugins/image-radius/`
3. 在後台啟用外掛
